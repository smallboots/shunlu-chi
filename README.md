# 顺路吃 · 校园食堂点评推荐

围绕「今天的口味 + 办事路线 + 食堂营业时间」推荐到具体菜品。虚构青禾大学，全部数据为演示数据。无需依赖、后端、密钥或登录。

## 最快发布到 GitHub Pages

1. 在 GitHub 创建一个 Public 仓库，例如 `shunlu-chi`。
2. 点击 **Add file → Upload files**，把本目录中的 `index.html`、`style.css`、`app.js` 上传到仓库根目录并提交。不要把整个外层文件夹作为根目录里的子目录上传。
3. 打开 **Settings → Pages**，Source 选择 **Deploy from a branch**，分支选 **main**，目录选 **/ (root)**，保存。
4. 等待部署完成，Pages 页面会显示可访问地址，一般是 `https://你的用户名.github.io/shunlu-chi/`。
5. 用未登录的浏览器或手机访问，确认页面和交互正常，再将这个完整链接提交到笔试系统。不要提交 GitHub 仓库地址。

后续始终更新同一个仓库，保持用户名、仓库名和 Pages 设置不变。不要提交临时预览地址。静态网站不依赖本地电脑持续运行；可用性仍取决于仓库与 GitHub Pages 服务。

## 功能

- 4 个食堂、12 道菜，按当天口味、预算、营业时间过滤。
- 多站行程排列优化；可固定先吃饭，综合比较额外步行与排队时间。
- 三个不同候选：综合推荐、少走路、少排队（均从剩余候选中选择）。
- 示意时间线包含步行、模拟排队、20 分钟用餐和每站 5 分钟取件。
- 点菜名看点评；星标收藏；本地点评与收藏使用 localStorage 保存。
- 11:25–12:35 和 17:25–18:35 附近到店增加模拟排队时间。到店未营业或排队结束已收餐的窗口会被排除；距离收餐不足 45 分钟提示菜品可能不全。

本原型不提供真实地图、库存、实时排队和跨用户点评。原始步行数据与菜品集中在 `app.js`，视觉样式在 `style.css`。

本地直接双击 index.html 可预览；正式演示请使用部署后的链接。浏览器禁用存储时会明确提示无法持久保存。
